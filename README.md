# hokie-passages

A little walking tour of my favorite spots around campus, from back when I
still bled maroon and orange. Mostly notes to myself.

## Stops
1. **The Drillfield** — start here at sunrise, it's worth it.
2. **Burruss Hall** — the limestone (we call it Hokie Stone) is the whole vibe.
3. **Torgersen Bridge** — cross it at least once a day, for luck.
4. **The Duck Pond** — where you go to actually think.
5. **War Memorial** — read the pylons. All eight words. Slow down for that one.

> My notes are public — if you know where to look.

_Ut Prosim._
